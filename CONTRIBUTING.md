
## Contribution Guide

Thanks for your interest in contributing. This list aims to provide excellent resources for Game Engine Development. It has been curated to provide the best examples available for each category and does not aim to be an exhaustive list of links to all available areas of Game Engine Development.

Inclusion is intentionally selective. A resource being relevant to Game Engine Development does not necessarily make it a good fit for this list.

With that said, here are a few basic guidelines for contributing:

- The link you are adding should not already be present in the list.
- The link you are adding should not take up more than a single line (i.e. should fit in the regular GitHub readme column).
- The link you are adding should include the proper [license emoji](https://github.com/stevinz/awesome-game-engine-dev#legend). The link and description should not include any additional emoji.
- The link's primary target should be a [GitHub](https://github.com/) repository (if applicable).
- The link you are adding should be relevant to Game Engine Development. New categories are possible if they improve the scope of the list as it pertains to Game Engine Development.
- The link you are adding should generally represent a stand-alone resource that is independently useful outside of the larger project it may belong to.
- The link you are adding should be currently maintained and not deprecated. Exceptions may be allowed for resources that are well known, historically significant, or have large community support.
- Resources whose primary purpose is AI-assisted development, LLM tooling, generative AI, or "vibe coding" are outside the scope of this list.
- The links that are listed for each category are in alphabetical order. New links should be inserted within this order.

## Submission Requirements

This is a curated list of established, high-quality resources, not a directory for promoting new projects.

For software projects hosted on GitHub:

- The project should be at least **six months old**.
- The repository should normally have at least **50 GitHub stars**.
- The project should show evidence of continued development, maintenance, meaningful community use, or otherwise established value beyond its initial release.
- Meeting these requirements does **not** guarantee inclusion. Projects must still be notable, useful, high-quality, and a strong fit for Game Engine Development.

Exceptions may be made for unusually important or unique resources, established projects hosted outside GitHub, official resources, historically significant projects, or specialized projects whose potential audience is inherently small.

## Pull Requests

Please submit **one project per pull request** and avoid opening multiple project-submission pull requests at the same time.

When submitting a project, please briefly explain why you believe it is a particularly useful or notable resource for Game Engine Development. Generic descriptions of what the project does are generally not enough to establish why it belongs on a curated list.

### No Promotional or Bulk Submissions

Please do not submit projects as part of a promotional campaign or bulk submission to Awesome lists.

- Submissions should come from someone who has actually reviewed this list and believes the project is specifically relevant to it.
- Automated, agent-generated, or mass-submitted pull requests are not accepted.
- Projects simultaneously submitted to large numbers of unrelated Awesome lists may be closed without review.

These rules are intended to keep contribution review focused on genuine recommendations rather than project promotion.

## Curation and Acceptance

Meeting the contribution requirements does not entitle a project to inclusion. This is an intentionally opinionated and curated list, and submissions may be declined at the maintainer's discretion to preserve its quality, focus, and usefulness.

A submission may be declined if:

- It does not adhere to these contribution guidelines.
- It is not a strong fit for a list about Game Engine Development.
- It substantially duplicates resources already represented in the same category.
- The maintainer does not believe it improves the overall usefulness or quality of the list.

## Existing Links

If you are the maintainer of a project or website already in this list and would like the link removed, or the description changed, feel free to submit a pull request to do so.
